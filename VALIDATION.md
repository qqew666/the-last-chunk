# Проверка версии 1.0.0

16 ноября 2026.

* Gradle `build`: **BUILD SUCCESSFUL**. Java-код скомпилирован для Java 17; JAR и sources JAR ремаппированы Loom для Fabric 1.20.1.
* `common:checkRound`: **Round clock: all checks passed**. Проверены 6000 тиков до выбора, ожидание выбора без переполнения, восстановление elapsed, сброс и отрицательное исходное значение.
* Запущена серверная среда разработки: Fabric Loader распознал `mirnaubyl 1.0.0` и загрузил серверную среду Mixin. Запуск остановлен Minecraft до создания мира, на требовании принятия EULA. Полный серверный игровой сеанс не выполнялся.
* Окно Minecraft, графический HUD, выбор и очистка мира в живом игровом сеансе вручную **не проверены**. Проверка сборки не заменяет проверку в игре.

Для локальной проверки: создай тестовый мир, выполни `/worldchoice now` (с включёнными читами), выбери камень; проверь шахту, инвентарь, сундук и новый чанк, затем перезайди. Повтори для воды и еды. Убедись, что таймер над хотбаром сбрасывается и снова заполняется за 5 минут игрового времени.

Сборка в ограниченном контейнере потребовала локально сообщить Loom об отсутствии поддержки Unix domain sockets; это относится только к среде проверки и не включено в проект или JAR мода. Для обычной сборки используется оригинальный Fabric Loom 1.7.4.
