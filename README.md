# the-last-chunk — Fabric 1.20.1

Мод-испытание для Minecraft Java Edition. Каждые **5 минут игрового времени** появляется выбор того, что навсегда исчезнет из мира. Зелёная шкала над хотбаром заполняется до следующего выбора.

## Правила

* **Блок** — удалить один указанный в меню вид блока (первый раунд: камень; затем случайный вид). Это не удаление всех блоков сразу.
* **Вода** — удалить воду, включая воду в заболоченных блоках, воду в котлах и вёдра воды (в том числе с водными существами).
* **Еда** — удалить съедобные предметы, торты и основные пищевые культуры: пшеницу, морковь, картофель, свёклу, арбузы, тыквы, сладкие ягоды и какао.
* Запреты накапливаются и сохраняются в данных конкретного мира. Вода и еда после удаления больше не предлагаются.
* Таймер останавливается на время выбора и когда на сервере нет игроков. 5 минут — это 6000 серверных тиков: при лагах реального времени пройдёт больше.
* На сервере решение общее: **первый ответ игрока выбирает за всех**. Наблюдатели не выбирают.
* Состояние синхронизируется раз в секунду. Выбор открывается автоматически, когда закрыты остальные экраны.

## Как происходит удаление «во всём мире»

Запрет действует во всех измерениях. Уже загруженные чанки очищаются постепенно с ограничением работы за тик, дальние и вновь созданные чанки — после загрузки. Мод не загружает весь бесконечный мир в память.

Удалённые блоки нельзя снова поставить. Запрещённые предметы очищаются раз в секунду из инвентарей игроков, эндер-сундуков, открытых экранов, загруженных контейнеров, инвентарей сущностей, экипировки и предметов на земле. Поддерживаются вложенные ванильные шалкеры и мешки (до 16 уровней). Офлайн-игроки и незагруженные контейнеры очищаются после входа/загрузки. Специальные хранилища других модов без стандартного Inventory и нестандартное NBT не гарантируются.

**Играй на отдельном мире или сделай резервную копию: изменения блоков необратимы.**

## Установка

1. Minecraft Java Edition **1.20.1**, Java **17 или новее**.
2. Установи Fabric Loader **0.16.10 или новее** для 1.20.1.
3. Положи Fabric API **0.92.2+1.20.1** и собранный `the-last-chunk-fabric-1.20.1-1.0.0.jar` в папку `mods`.
4. Для игры по сети установи мод и Fabric API **и на сервер, и на каждый клиент**.

Архив проекта — исходники, его нельзя просто положить в `mods`. Нужен JAR из сборки.

## Сборка

Нужны доступ в интернет и JDK 21 для сборки; итоговый мод нацелен на Java 17.

Windows (из папки проекта):

```bat
gradlew.bat build
```

Linux / macOS:

```sh
chmod +x gradlew
./gradlew build
```

Результат: `fabric-1.20.1/build/libs/the-last-chunk-fabric-1.20.1-1.0.0.jar`.
Файл с `-sources` в имени — исходники, для установки нужен обычный JAR.

Запуск среды разработки: `./gradlew :fabric-1.20.1:runClient`.
Проверка таймера: `./gradlew :common:checkRound`.
Операторская команда `/worldchoice now` немедленно открывает выбор для проверки.

## Структура

* `.github/workflows/build.yml` — автоматическая сборка и артефакты GitHub Actions.
* `common/` — таймер, не зависящий от Minecraft, и его проверки.
* `fabric-1.20.1/` — серверная логика, сохранение, меню, HUD и mixin.
* `gradle/wrapper/`, `gradlew`, `gradlew.bat` — Gradle Wrapper 8.8.
* `build.gradle`, `settings.gradle`, `gradle.properties` — настройки проекта.
* `LICENSE` — MIT.

Структура создана по образцу снимка; код и содержимое чужого проекта не копировались. Другие версии Minecraft не заявлены и не включены. `.gradle/` создаётся автоматически при сборке и в архив не включается.

## GitHub

В проект включена автоматическая сборка на push и ручной запуск в Actions → Build Fabric 1.20.1. После успешной сборки скачай артефакт `the-last-chunk-fabric-1.20.1`.

Чтобы создать собственный новый публичный репозиторий из этой папки через GitHub CLI:

```sh
gh auth login
git init -b main
git add .
git commit -m "Add The Last Chunk Fabric 1.20.1 mod"
gh repo create the-last-chunk --public --source=. --remote=origin --push
```

Название мода — **The Last Chunk**. Технический ID `mirnaubyl`, сетевые каналы и ключ данных мира сохранены для совместимости с предыдущей версией. При обновлении замени старый JAR новым: не оставляй оба файла в `mods`.
